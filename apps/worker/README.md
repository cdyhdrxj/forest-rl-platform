# Фоновые задачи

Каталог зарезервирован под отдельный worker-процесс, но сейчас worker не входит в `docker-compose.yml` и не является обязательной частью запуска.

## Где сейчас выполняется фоновая работа

- Runtime-наблюдение и запись артефактов выполняет `RunObserver` внутри `apps/api`.
- Headless scientific suites запускаются отдельной CLI-командой `python -m experiments.scientific.run_suite --config ...`.
- Долгие training/evaluation операции пока управляются через runtime-сервисы и dispatcher, а не через очередь задач.

## Когда сюда добавлять код

Если появится очередь задач, scheduler или отдельный процесс для тяжелых расчетов, этот каталог может стать точкой входа worker-приложения. Тогда нужно будет обновить `docker-compose.yml`, документацию запуска и правила хранения артефактов.
