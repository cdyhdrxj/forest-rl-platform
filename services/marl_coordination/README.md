# Многоагентный режим

Каталог зарезервирован под многоагентную координацию, но текущий платформенный runtime `v1` еще не содержит полноценного MARL-контракта.

## Текущий статус

- В `services/marl_coordination` пока нет исполняемых модулей.
- `contracts/v1/*` не описывают multi-agent payloads.
- `contracts/websocket_protocol.md` явно оставляет multi-agent за пределами `v1`.
- В документации проекта многоагентный режим описан как направление развития, а не как готовый runtime route.

## Что нужно будет определить перед реализацией

- формат multi-agent scenario и `runtime_config`;
- action/observation space для нескольких агентов;
- структуру replay/events с `agent_id` или `robot_id`;
- правила агрегации reward, episode status и метрик;
- WebSocket/API расширение или новую версию контракта.

Пока эти решения не приняты, внешний разработчик не должен ожидать, что каталог можно запустить как готовый сервис.
