# Управление роботом (клеточная среда)

Этот каталог содержит автономный учебный DQN-прототип для клеточной среды.

## Что здесь есть

- `environment.py` - генерация случайной grid-среды и простая динамика агента.
- `dqn.py`, `agents.py`, `trainer.py` - базовая DQN-логика и обучение.
- `run_dqn.py` - локальный пример запуска обучения.
- `description.ipynb` - исследовательское описание/черновик.

## Чего здесь нет

Этот прототип не подключен к современному backend dispatcher, БД, replay writer и WebSocket UI. Он не является runtime route из `apps/api/dispatcher.py`.

Актуальный разделенный контур управления роботом описан в `services/robot_control/README.md`, а платформенный жизненный цикл run - в `docs/runtime/README.md`.
